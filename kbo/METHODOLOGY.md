# 밸류트랙 KBO — 기술 방법론 리포트 (v2: 선수 단위 bottom-up)

> 대상: 2026 KBO 정규시즌 + 한국시리즈 · 예측 결과는 [report.md](report.md), 산출물은 [outputs/kbo.json](outputs/kbo.json).
> 이 문서는 **어떤 데이터·피처·모델을 썼는지**를 정리합니다.

v1(팀 시즌 합계 기반)에서 **선수 단위 bottom-up**으로 확장한 버전입니다: 선수 스탯을
모아 가치(WAR)를 매기고, 라인업·출전·감독 전술로 팀 전력을 쌓아 시즌을 시뮬레이션합니다.
연봉은 **표시용으로만** 추정하며(실연봉 레퍼런스로 검증) 시뮬에는 들어가지 않습니다.
엔진은 **2015–2019 실제 전체 로스터로 백테스트 검증**되었습니다.

---

## 1. 파이프라인

```
선수 스탯 ── 가치(WAR) ─┬─ 승리환경(WAR+시너지) ─┐
(전체 로스터)            └─ 추정연봉(표시용)        │
   │                                              │
   └─ 라인업 · 출전 preset · 감독전술 ────── 팀 공격/수비 득점(rs/ra) ┴ 144경기 + 한국시리즈 몬테카를로 ── 우승확률
```

| 단계 | 모듈 | 역할 |
|---|---|---|
| 데이터 | `boxscore_data.py` | 공개 박스스코어 덤프 로드 + **at-bat 코드 디코딩** → 전체 선수 시즌 스탯 |
| 가치 | `player_value.py` | wOBA·wRC+·FIP·**WAR(포지션 보정 포함)** |
| 연봉 | `salary_model.py` | WAR→₩ 추정 연봉/가치 (+실연봉 레퍼런스로 검증) |
| 로스터 | `roster.py` | 라인업 + **출전 시간 preset**(잘하는 선수 우선 + 전체 기용) |
| 전술 | `manager_tactics.py` | 팀별 불펜 레버리지 등 소폭 조정(공개·비활성 가능) |
| 전력 | `team_build.py` | 선수→팀 공격/수비 득점 + **승리환경(WAR+시너지)** |
| 시뮬 | `game_model·season_simulate·postseason` | (v1 재사용) 음이항 득점, 144경기, 사다리 |
| 2026 | `live2026.py` | /Record 규정선수 + 팀합계 앵커 벤치 |
| 검증 | `backtest.py` | 2015–2019 실제 결과와 비교 |

- 전체 로스터: 시즌당 **타자 ~250–300명, 투수 ~250명**(전 선수, 포지션 포함).
- **박스스코어 API(`/ws/`)는 robots.txt가 차단 → 미사용**(statiz와 동일 원칙). 대신 이미
  공개된 LOPES 덤프 사용.
- 깨끗한 10구단·144경기 백테스트: **2015·2016·2017·2018·2019** (2020은 덤프상 부분).

### at-bat 코드 디코딩
타격 안타 종류는 이닝별 코드(`i_1..i_12`)로 인코딩 → kbodatatools 규칙으로 디코딩:
`1B 1000–1029 · 2B 11xx · 3B 12xx · HR 13xx · BB 30xx/32xx · IBB 32xx · HBP 31xx · SF 50xx · SH 41xx/61xx · GDP 72xx`. 8자리 코드는 두 이벤트로 분해. **검증: 박병호 2015 → 53 HR, 디코딩 안타 = 실제 안타.** (삼진은 wOBA에 불필요해 미디코딩.)

## 3. 피처

- **원시 스탯(타격)**: PA, AB, H, 1B, 2B, 3B, HR, BB, IBB, HBP, SF, SH, GDP, R, RBI, **포지션**, G.
- **원시 스탯(투구)**: IP, 피안타, 피홈런, 사사구, 삼진, 실점, 자책, 투구수, 등판, 선발/불펜.
- **파생 가치**: wOBA, wRAA, **wRC+**, **FIP**, **WAR**(타자=wRAA+포지션보정+대체수준÷RPW; 투수=FIP 기반).
- **연봉**(표시 전용): WAR→₩ (하한 3천만, 상한 25억, 볼록 곡선; 나이 틸트 옵션). 실연봉 상한은
  더 높지만(~25–42억) 이 격차는 검증 지표로만 보고(시뮬은 연봉 미사용이므로 상한은 표시 안정용).
- **팀 입력(시뮬)**: `rs_per_game`(PA가중 wOBA), `ra_per_game`(IP가중 RA9+FIP 블렌드).
- **승리환경**: 팀 **WAR 합**(전력/투자 지표) + synergy(뎁스: 평균 이상 선수 수) z-score, 소폭.
  연봉이 아니라 WAR을 직접 사용(추정연봉은 표시용).

---

## 4. 모델 핵심 선택

- **팀 공격 = 출전(PA) 가중 평균 wOBA → 득점.** 실제 팀 득점과 **상관 0.96**, 분산 일치.
- **팀 수비 = 출전(IP) 가중 RA9(실제 실점률) + FIP 소폭 블렌드.** 순수 FIP는 수비를 배제해
  과소분산 → RA9 블렌드로 실제 실점과 **상관 0.99**.
- **출전 preset**: 가치 순 지수 가중(상한 700 PA), `breadth`로 스타 집중↔전체 기용 조절. ΣPA≈5700, ΣIP≈1290.
- **승리환경**: WAR+시너지의 **작고 공개된 modifier**(가중치 기본 0.04, 끌 수 있음) — 이미 스탯에
  반영된 실력을 이중 계산하지 않도록 소폭. 시뮬은 연봉이 아닌 **WAR**에 의존(연봉은 표시 전용).
- **경기/시즌/포스트시즌**: v1 검증 엔진 재사용(음이항 득점 k≈3.64, 홈 1.10, 144경기, WC→준PO→PO→KS).

## 5. 검증 (백테스트 2015–2019, 전체 실제 로스터)

| 지표 | 결과 | 의미 |
|---|---|---|
| 순위 상관 (Spearman ρ) | **≈0.84** | 선수→팀→순위 재현 |
| 우승 정확 적중 | **40%** (2/5) | KBO 사다리 변동성상 준수 |
| 실제 우승팀 평균 부여확률 | **29%** | 무작위 10%의 약 **3배** = 실질 신호 |
| 개별 검증 | 박병호 53HR · 테임즈 10.7 WAR(2015 MVP) · 김도영 · 폰세 | 스타/MVP 상위 |
| 캘리브레이션 | 공격 0.96 / 수비 0.99 | 실제 득점·실점 재현 |
| 연봉 검증(신규) | corr(WAR,연봉)≈0 · 곡선 ~3× 과소추정 | 실연봉 상위표본은 **절단**(≥₩13.65억)이라 재적합 불가 → 검증용(연봉은 표시 전용) |

## 7. 한계

1. **2026 뎁스 근사**: 박스스코어 robots 차단 → 규정선수(실데이터) + 팀합계 앵커 벤치. 엔진 자체는
   2015–2019 전체 실데이터로 검증.
2. **포지션**: 2026 /Record엔 포지션 없음 → 내야 기본값(선수 WAR 표시만 영향, 팀 rs/ra 무관).
3. **WAR**: 주루(SB/CS 없음)·정밀 수비 생략. 구장 보정 중립.
4. **연봉**: WAR 기반 **가치** 추정(실연봉 회귀 아님). 실연봉 레퍼런스(스탯티즈 역대+KBO 2026 공식)는
   상위 연봉자만 담긴 절단 표본(≥₩13.65억, corr(WAR,연봉)≈0)이라 이걸로 곡선을 재적합하면 ~₩18억 상수로
   붕괴 → **검증에만** 사용(선수 리더보드엔 매칭 선수 실연봉을 표시용으로 병기).
5. **독립 경기 노이즈**: 시즌 분산 과소 → 1순위 확률 다소 과대.
