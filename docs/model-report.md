# 밸류트랙(ValueTrack) — 모델 종합 보고서

블링커스 주식회사 · 2026년 7월 · 투자 검토용

---

## 요약

- **한 문장 정의**: 밸류트랙은 선수의 경기 기록만 넣으면 예상 이적료를 근거까지 붙여 계산해 주는 스포츠 가치 평가 엔진입니다.
- **제품 수**: 이 엔진 하나를 축으로 **축구 5종 + 야구 1종, 모두 6개 모델**을 만들었습니다.
- **검증된 성능**:
  - 축구 이적료 모델 — 학습에 쓰지 않은 실거래 **292건에서 평균오차 €5.35M, 순위 상관 0.85**
  - KBO 우승 예측 — 과거 **5개 시즌 백테스트에서 순위 상관 0.84**
- **데이터 탄력성**: 학습 데이터를 5배 늘리자 오차가 **63% 감소**. 지금은 데이터를 넣는 만큼 성능이 오르는 구간입니다.

## 모든 예측을 관통하는 세 가지 방법

밸류트랙의 모든 제품은 아래 세 층을 쌓아 만듭니다. 이 세 층을 함께 갖췄다는 점이 우리의 경쟁력이자, 경쟁사가 쉽게 따라올 수 없는 진입 장벽입니다.

| 단계 | 하는 일 | 축구에서는 | 야구에서는 |
|:--:|---|---|---|
| **① 몸값 예측** | 선수 개인 기록 → 몸값 | 이적료(€) 산정 | 승리기여도(WAR) 산정 |
| **② 시너지** | 개별 가치 → 팀 전력 | 스쿼드 조합·조직력 반영 | 라인업·출전·감독 전술 반영 |
| **③ 시뮬레이션** | 팀 전력 → 확률 | 대회·시즌 몬테카를로 | 정규시즌+가을야구 몬테카를로 |

- 몸값만 있으면 되는 제품(이적료·행선지)은 **①에서 멈춥니다.**
- 우승을 다투는 제품(월드컵·프리미어리그·KBO)은 **①②③을 모두 씁니다.**
- 엔진은 하나지만, 이 세 층을 어디까지 쌓느냐에 따라 제품이 갈립니다. 종목을 새로 붙일 때마다 엔진을 다시 만들지 않습니다.

# 축구 모델

## 1. 핵심 엔진 — 이적료 평가 [①]

지도학습 회귀 모델(XGBoost)입니다. 밸류트랙의 모든 축구 제품이 이 엔진 위에 올라탑니다.

**데이터**

- 출처: 공개 데이터 묶음 하나(worldfootballR)에서 세 갈래 자료를 끌어와 붙였습니다.
  - FBref 경기 스탯 6종 (2010–2023, 유럽 5대 리그)
  - 트란스퍼마르크트 실거래 이적료
  - 시장가치 이력
- 학습 데이터: 유럽 5대 리그 **실거래 이적료 약 2만 4천 건** (2010–2022)을 경기 스탯과 결합해 학습했습니다.
- 수집 방식: 실시간으로 긁어오지 않고 **정적 파일만 받아 씁니다.**
- 지표: 후보 80여 개를 통계 기법 3종(LASSO·RFE·상호정보량)으로 교차 검증해 **30개**로 추렸습니다.

**성능** *(학습에 쓰지 않은 2021–22년 실거래 292건 기준)*

| 구분 | 결과 |
|---|---|
| 평균 절대오차(MAE) | **€5.35M** |
| 순위 상관(가치 순으로 세우는 정확도) | **0.85** |
| 단순 선형 모델 대비 | 오차 **−57%** (€12.37M → €5.35M) |
| 데이터 5배 확대 효과 | 오차 **−63%** (€14.4M → €5.35M) |

**차별점 — 근거를 함께 냅니다**

- 금액만 내놓고 끝내지 않습니다. 어떤 지표가 그 값을 끌어올렸는지 뜯어 보여줍니다.
- 예: *"유효슈팅을 늘리면 +€13M, 나이가 한 살 어렸다면 +€11M"* 처럼 올릴 여지까지 짚어 줍니다.
- 값만 알려 주는 자동차 시세표(켈리 블루북)와 갈라지는 대목입니다.

# 야구 모델

## 4. KBO 우승 예측 — 세 방법을 모두 갖춘 완성형 [①②③]

팀 성적을 뭉뚱그리지 않고 선수 한 명 한 명에서부터 쌓아 올리는(상향식) 몬테카를로 시뮬레이션입니다.

**파이프라인**

- **① 몸값**: 타자·투수 기초 기록 → 세이버메트릭스 지표(wOBA·wRC+·FIP·WAR)로 환산
- **② 시너지**: 라인업·출전 시간 배분·감독 전술로 엮어 팀 공격력·수비력 산출
- **③ 시뮬레이션**: 144경기 정규시즌 + 가을야구를 **50만 번** 반복

**데이터**

- 고급 지표는 남의 계산을 가져다 쓰지 않고, 득점이 많이 나는 KBO 환경에 맞춰 **직접 계산**했습니다.
- 학습 기록: 2010–2020년 전체 로스터의 경기 단위 데이터 — **타자 17만 3천 건 · 투수 5만 9천 건.**

**백테스트** *(2015–2019년, 실제 로스터로 되돌려 검증)*

| 시즌 | 순위 상관 | 우승 적중 |
|:--:|:--:|:--:|
| 2015 | 0.855 | ✗ |
| 2016 | 0.863 | ✓ |
| 2017 | 0.912 | ✗ |
| 2018 | 0.695 | ✓ |
| 2019 | 0.872 | ✗ |
| **평균** | **0.84** | **2/5 (40%)** |

- 실제 한국시리즈 우승팀에 부여한 평균 확률은 **29%**로, 무작위(10%)의 약 **3배**입니다.
- 짧은 시리즈라 우승팀 자체를 매번 맞히지는 못하지만, **후보를 좁혀내는 힘은 뚜렷합니다.**

**2026 시즌 예측**

- 우승 1순위: **삼성 (약 52%)**
- 선수 가치(WAR) 1위: **LG 오스틴** (wRC+ 198)

**데이터 원칙**

- 특정 통계 사이트를 몰래 긁어오지 않았습니다.
- 로봇 배제 표준(robots.txt)이 허용한 공식 기록과 공개 덤프만 썼고, 수집이 막힌 통계 사이트(스탯티즈)는 처음부터 손대지 않았습니다.

# 공통 사항

## 데이터 적법성

- 모든 제품은 실시간 스크래핑이 아니라 **정적인 공개 데이터**를 씁니다.
- 로봇 배제 표준을 지키고, 수집이 막힌 사이트는 처음부터 손대지 않습니다.
- 바탕 데이터가 경기 기록·이적료 같은 **사실**이라 저작물로 보호받는 성격이 약하고, 그만큼 연구·MVP 단계의 법적 위험도 낮습니다.
- 다만 **사업화 단계에서는** 정식 데이터 라이선스(옵타, 트란스퍼마르크트 등) 계약이 필요하며, 이 비용과 일정은 미리 계산에 넣어 둬야 합니다.

## 성장 여력

- 지금 발목을 잡는 건 기술이 아니라 **데이터 확보 범위**입니다. 축구 모델을 5대 리그 1부에서 **하부 리그까지** 넓히면 평가할 수 있는 선수가 몇 배로 늘어납니다.
- 필요한 준비물은 두 가지입니다.
  - 하부 리그 **경기 스탯** 확보
  - 리그 간 수준 차이를 메울 **리그 강도 지표**
- 이를 갖추면 순위 상관을 **0.88–0.92**까지 끌어올릴 수 있다고 봅니다.
- 데이터를 넣는 만큼 성능이 오르는 지금 국면이 이번 투자의 핵심 근거입니다.

각 모델이 아직 설명하지 못하는 부분을 한자리에 정리했습니다.

| 영역 | 한계 | 대응 |
|---|---|---|
| **이적료 엔진** | 초대형 거래(메가딜)를 실제보다 낮게 잡습니다 — 스타·협상 프리미엄이 스탯으로 설명되지 않기 때문입니다 | 시장 대부분을 차지하는 중상위권은 오차가 작아, 이 구간을 1차 타깃으로 삼습니다 |
| **대회 시뮬** *(월드컵·EPL)* | 아직 열리지 않은 대회라 정확도가 검증되지 않았고, 독립 시뮬 특성상 1순위 확률이 다소 높게 나옵니다 | 확률값보다 **순위**로 해석하고, 대회가 끝난 뒤 사후 검증합니다 |
| **KBO** | 한국시리즈는 경기 수가 짧아 우승팀을 단정하기 어렵습니다. 추정 연봉은 표시용이며 개별 예측이 아닙니다 | 순위·확률로 해석합니다. 엔진 자체는 5개 시즌 백테스트로 검증됐습니다 |
| **데이터 커버리지** | 5대 리그 1부 위주여서 스탯이 없는 선수 절반가량은 평가하지 못합니다 | 하부 리그 스탯·리그 강도 지표를 확보하면 해소됩니다 *(→ 성장 여력)* |
| **데이터 권리** | 상업화 단계에서는 정식 데이터 라이선스가 필요합니다 | 비용과 일정에 미리 반영합니다 *(→ 데이터 적법성)* |

- 공통적으로, 모델은 **금액의 절대값보다 순위를 훨씬 정확하게** 맞힙니다. 스카우팅·평가 실무에서 더 중요한 것이 순위 매김이라는 점에서, 이 특성은 약점인 동시에 제품이 겨냥하는 지점과도 맞닿아 있습니다.
